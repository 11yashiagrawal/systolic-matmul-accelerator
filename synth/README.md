# Synthesis (Phase 2)

Phase 2 adds synthesis and timing results for the accelerator and for a single-MAC sequential baseline:

- `yosys/`: open-source synthesis for resource counts (LUTs, flip-flops, DSPs);
- `vivado/` and `constraints/`: Xilinx flow for resource utilization and maximum frequency, if a board or Vivado licence is available;
- reports that the final report cites are copied to `results/phase2/`.

Nothing here is required for Phase 1.
