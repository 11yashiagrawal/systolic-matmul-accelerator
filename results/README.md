# Results

Committed evidence that the report and the video cite. Everything else that simulation produces goes to `build/` and is not committed.

| Folder | Contents |
|---|---|
| `phase1/waveforms/` | annotated GTKWave captures (PNG) of the PE, the array and the top level |
| `phase1/logs/` | testbench logs with `PASS`/`FAIL` summaries and random seeds |
| `phase1/cycle_counts.csv` | measured compute latency per test, against the `K + 2N - 2` formula |
| `phase2/` | synthesis, timing and baseline comparison (Phase 2) |
